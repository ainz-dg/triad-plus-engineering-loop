## Verification boundaries

- The smoke selects `opencode,codex,claude-code,copilot,antigravity,hermes` in one TUI session and approves one install preview.
- A minimal fixture `PATH` exposes only the fixture `git` and `python3`; `HOME`, `XDG_CONFIG_HOME`, `CODEX_HOME`, `HERMES_HOME`, and temporary files are isolated. Ambient credential-like environment variables are stripped from test child processes.
- The smoke asserts `adapter list` reports each adapter as `project=installed global=not_configured host=unavailable`; `adapter doctor` reports host unavailability/unsupported dispatch and leaves every file in the Control Workspace byte-identical.
- No host is started, no network/LLM call is made, and no inference is made about native discovery or dispatch from files merely being present.
