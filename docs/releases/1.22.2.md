# Triad+ 1.22.2

Patch release notes for PR #41.

## Product changes

- Fix managed `AGENTS.md` ownership and integrity across `doctor`, upgrade,
  and adapter removal. User-authored text outside Triad+ markers is preserved;
  a changed managed block is rejected before writes.
- Separate first-run installation from host-runtime discovery and project
  readiness. The KISS wizard presents a concise installation plan, supports
  optional full details, and requires exact-path review before applying a
  selected user-level entry.
- Improve the setup logo and TUI behavior across terminal sizes, including a
  readable `TERM=dumb` fallback. Blocking setup preflight/apply failures have
  clearer nonzero outcomes and next steps.

## Validation and scope

- Regression coverage includes Linux PTY runs at 80x24, 80x20, and 60x20,
  alongside cancellation, blocking preflight, recovery, and dumb-terminal
  fallback. PTY coverage is not a claim of perfect subjective UX on every
  console.
- Project-local adapter installation does not establish that a native host
  executable is installed, discovered, or usable. The first-run summary does
  not attest to project readiness or run quality gates; selected mappings
  still undergo setup preflight validation. `doctor` remains a separate
  installation/host diagnostic.
- This patch contains no Core, verifier, Reviewer, or adapter-dispatch changes.
