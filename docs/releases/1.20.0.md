## Candidate scope

The release delta from `v1.19.0` contains three commits: PR #17's documentation
alignment, PR #18's human-first Card report and Delivery handoff entries in the
read-only Cockpit, and PR #19's mobile Markdown containment. This candidate
adds a single OpenCode first-loop tutorial and a small set of clearly labeled
synthetic screenshots. The tutorial covers setup prerequisites, a separate
Control Workspace, a real interactive `/triad` host step, evidence, explicit
report materialization, and Cockpit interpretation.

The project-level **Delivery handoff** and Card-level **Card report** are
shortcuts to existing Markdown files. Their presence does not approve a Card,
validate a Reviewer verdict, or deliver a project. Cockpit remains read-only,
does not launch agents, does not establish liveness, and does not generate the
reports. Its Markdown viewer keeps prose in a readable column while wide
tables and code blocks scroll independently on narrow screens.

This preparation introduces no package API, workspace schema, or runtime
dependency changes. That observation is limited to the scoped candidate diff
and is not a universal compatibility guarantee. No breaking change is
identified in this documentation/release-preparation tranche.
