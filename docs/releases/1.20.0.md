# Triad+ 1.20.0

**Previous release:** `v1.19.0` at
`f3833e071fe03c5396babc3117529987368522e3`

**Change set:** PR #17, PR #18, PR #19, and PR #20.

## Scope

The 1.20.0 change set follows `v1.19.0`: PR #17 aligns release and onboarding
documentation; PR #18 adds human-first Card report and Delivery handoff entries
to the read-only Cockpit; PR #19 keeps Markdown content within mobile width;
and PR #20 adds the OpenCode first-loop tutorial and synthetic screenshots.
The tutorial documents setup prerequisites, a separate Control Workspace, an
interactive `/triad` host step, evidence, explicit report materialization, and
Cockpit interpretation.

The project-level **Delivery handoff** and Card-level **Card report** are
shortcuts to existing Markdown files. Their presence does not approve a Card,
validate a Reviewer verdict, or deliver a project. Cockpit remains read-only,
does not launch agents, does not establish liveness, and does not generate the
reports. Its Markdown viewer keeps prose in a readable column while wide
tables and code blocks scroll independently on narrow screens.

## Behavior and boundaries

The screenshots use a fabricated, labeled demo workspace, not a real three-
agent run, benchmark, private M1B input, or evidence of OpenCode execution.
Verifier evidence is tied to the recorded artifact fingerprint at the time it
was produced; it does not continuously re-check a subsequently changed
artifact.
Reviewer summaries and other agent-declared reports remain distinct from
validated verifier verdicts. Evaluator+ is optional after approval and is not
a fourth role or repair controller. No new Triad+ Core/runtime capability is
introduced in this tranche; Cockpit remains read-only and does not launch
agents, establish liveness, or generate reports.
