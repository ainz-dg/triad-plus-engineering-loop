# Triad+ 1.22.3

Patch release notes for PR #42.

## Product changes

- Clarify first-run setup labels and stages. Suggested repository defaults are
  shown together, with one explicit `edit` path for advanced fields.
- Add semantic terminal colors for prompts, review, success, and errors, with
  fallbacks across truecolor, 256-color, ANSI, `NO_COLOR`, and `TERM=dumb`.
- Distinguish installation from project readiness. Next steps identify the
  root PRD, quality gates, initial commits, and mapped worktrees; the getting
  started documentation is updated.

## Validation and scope

- Tested on Linux PTYs at 80x24, 80x20, and 60x20, including cancellation,
  consent and no-write-before-install behavior, and global-entry safeguards.
  No new TUI framework is introduced. These checks do not claim subjective UX
  perfection on every terminal or host.
- No Triad+ Core, verifier, Reviewer, adapter-dispatch, Evaluator+, security
  boundary, or release-workflow behavior changes are included.
