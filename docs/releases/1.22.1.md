# Triad+ 1.22.1

## Product changes

- Carry forward the Retro Pixel terminal header and the narrow-terminal TUI
  stability fixes from PR #35, including bounded inline error rendering that
  preserves selection and focus.

## Release process

- Introduce a manually dispatched GitHub Actions workflow with a side-effect-
  free dry-run as the default and a separate, explicit publish selection.
- Build and validate one package archive, then use those same bytes for npm
  publication and the two GitHub Release assets.
- Use npm Trusted Publishing through GitHub Actions OIDC; no static npm token
  is part of the release process.

The release workflow and owner prerequisites are documented in
[GitHub Actions release guide](../maintainers/releasing.md).
