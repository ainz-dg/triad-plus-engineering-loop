# Triad+ 1.17.0 — release notes

**Version:** 1.17.0 (minor). These notes describe the release candidate in the
associated PR; publication remains gated on independent review of its exact
head SHA.

## Summary

This candidate packages the opt-in multi-adapter installation inventory and
its conservative lifecycle operations, with a terminal-first management path
in the existing readline wizard. Existing schema-v1 installations remain
readable; migration to schema v2 occurs only after an explicit successful
adapter add. The wizard detects a valid manifest in the current directory and
defaults to management; otherwise it defaults to new workspace setup, and
requires an explicit path to manage an existing directory. It never scans
sibling directories.

## Breaking changes

No breaking changes are intended. The TUI calls the existing project-local
adapter lifecycle and does not change host selection or dispatch behavior.

## Migration

No migration is required to continue using an existing v1 installation. From
the TUI, choose Add adapter, inspect the CLI dry-run plan, and type the exact
word `apply` to proceed. The equivalent advanced command is
`triad-plus adapter add <id> --control <path> --apply`. That operation migrates
the installation record to schema v2. The same menu exposes list, doctor,
upgrade, remove, and exit; all mutations are project-local and require a
read-only preflight followed by explicit confirmation. Global multi-adapter
assets are not supported.

## Limitations

- Adapter inventory/lifecycle is not per-Attempt host selection and does not
  provide automatic cross-attempt handoff. Attempt dispatch remains
  unsupported.
- A CLI being present, or an adapter being installed, does not prove host-native
  project-local discovery or end-to-end delegated execution. Codex and Hermes
  entry points remain limited/unproven; other host discovery must be reported
  only when actually observed.
- The accepted local-filesystem path-resolution TOCTOU limitation remains
  unresolved and is appropriate only for a trusted single-user local workspace.
- This draft makes no six-host runtime, paid-model, or native discovery claim.
