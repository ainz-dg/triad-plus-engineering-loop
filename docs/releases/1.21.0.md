# Triad+ 1.21.0

**Previous release:** [v1.20.1](https://github.com/ainz-dg/triad-plus-engineering-loop/releases/tag/v1.20.1), commit `98a3b32aaa8246705a10f42c28f4eae217fcd6e9`.

**Change set:** [PR #25 — P0 keyboard onboarding TUI](https://github.com/ainz-dg/triad-plus-engineering-loop/pull/25), merged at `39ba2eb585f303a4022210345c1078a2a5818d10`.

## What's new

The first-run wizard replaces the text-only repository and adapter selectors with real terminal checklists.

- Select existing Git repositories using Up/Down, Space and Enter. Only the explicit Control Workspace's immediate-child Git roots are suggested; external local repositories require an explicit path.
- Derive editable stable repository IDs from the selected directory basename. Suggest the detected base branch and matching project branch/worktree mapping, without assuming selection from a numeric ID.
- Select one or multiple coding-agent adapters with true keyboard checkboxes. The first selected adapter is shown as the primary host for existing singleton metadata. Multi-adapter installation works; automatic per-Attempt multi-harness dispatch is **not available**.
- Navigate back from harness selection without losing repository choices; handle Escape/Ctrl+C and terminal raw-mode cleanup. Honor `NO_COLOR` and constrained terminal widths.
- Preserve greenfield and defer choices, preview-only plan and exact `install` confirmation; before confirmation there is no product repository modification, worktree creation, global host setting change or agent/provider invocation.

## What is not yet redesigned

This is the P0 user-experience improvement, not the completed five-step Basic/Advanced onboarding. Workspace path, repository details, greenfield path collection, and optional team/persona/model configuration still include textual prompts. Model IDs entered by users are not proof of provider/host availability; no runtime model discovery is claimed. The Cockpit remains a read-only view, not a live execution control surface.

Triad's Orchestrator, Developer and independent Reviewer roles are unchanged. The verifier remains deterministic and separate from semantic review; Evaluator+ remains optional and post-approval.

## Compatibility and testing

No new runtime dependencies or additional agents/subsystems. Noninteractive CLI workflows and the six-adapter ownership manifest remain compatible. The PR adds repeatable PTY keypress regression coverage, including no-write-before-approval and packaged CLI smoke. Release publication remains conditional on tests and package integrity passing on the final pinned 1.21.0 source SHA.

## Installation

From an empty, separate Control Workspace directory:

```bash
npx triad-plus@1.21.0
```

Do not use the product repository itself as the Control Workspace. After setup, project readiness (PRD, quality gates, repository commit, mapped worktree) is a separate check; installed adapters alone do not prove that a Triad loop is ready.
